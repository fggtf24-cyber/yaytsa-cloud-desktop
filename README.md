# Яйца Cloud для Windows

Приложение сайта [Яйца Cloud](https://fggtf24-cyber.github.io/yaytsa-cloud/): все программы с сайта в одном окне.

- «Установить», «Открыть», «Обновить» и «Удалить» прямо на карточках программ
- сам замечает новые версии программ
- лента, профиль и чаты: внутри открыт живой сайт, новые функции появляются без обновления приложения
- сообщения, ответы и лайки приходят уведомлениями Windows
- значок в трее, запуск вместе с Windows
- обновляется сам из последнего релиза

## Установка

Скачайте `YaytsaCloud.exe` из [последнего релиза](https://github.com/fggtf24-cyber/yaytsa-cloud-desktop/releases/latest) и запустите. Приложение поставит себя в `%LOCALAPPDATA%\Programs\YaytsaCloud`, создаст ярлыки и откроется. Права администратора не нужны. Удаляется через «Параметры → Приложения».

Нужны Windows 10 или 11 (64-бит). .NET Framework 4.8 и WebView2 в них уже есть.

## Сборка

```
dotnet build -c Release
```

Готовый файл: `bin\Release\net48\YaytsaCloud.exe`. Библиотеки WebView2 вшиты в него.

Запуск без установки, с локальной копией сайта: `YaytsaCloud.exe --portable --url http://localhost:4173/`

## Как сайт говорит с приложением

Сайт узнаёт приложение по `YaytsaCloud/` в User-Agent и общается через `window.chrome.webview.postMessage`:

- сайт → приложение: `catalog` (список программ), `install`, `open`, `remove`, `notify`
- приложение → сайт: `apps` (что установлено и что обновить), `go` (клик по уведомлению), `error`
