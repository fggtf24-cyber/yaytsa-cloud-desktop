# Яйца Cloud для Windows

## Не запускать установленное приложение пользователя

Никогда не запускай `%LOCALAPPDATA%\Programs\YaytsaCloud\YaytsaCloud.exe` из своей командной строки (Bash, PowerShell, `cmd /c start`) и не перезапускай его за пользователя после проверок. Так запущенное приложение портит папку данных браузера `%LOCALAPPDATA%\YaytsaCloud\web`: пропадает вход в аккаунт и не работает микрофон, и это остаётся даже после запуска пользователем. 11.11.2026 помогло только перенести `web` в `web.bak` при закрытом приложении.

Как проверять:
- своей сборкой: `bin\Release\net48\YaytsaCloud.exe --portable --url http://127.0.0.1:<порт>/` на тестовой странице;
- если нужна проверка на живом сайте в установленном приложении — закрыть его (`YaytsaCloud.exe --quit`) можно, а открыть пусть пользователь сам из «Пуска».

## Выпуск

Поднять `<Version>` в `YaytsaCloud.csproj`, `dotnet build -c Release`, запушить и создать релиз `vX.Y.Z` с файлом `bin\Release\net48\YaytsaCloud.exe`. Установленные приложения скачивают его сами и включают со следующего запуска.
